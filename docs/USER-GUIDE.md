# Using AGAIN
1. Open Quick Tools → Image workflow.
2. Add crop, text, logo or other supported image steps. Use 0.8 for a 4:5 crop.
3. Select input files and an output folder. Naming supports `{original-name}`, `{number}`, `{date}` and other saved variables.
4. Preview each image. The same rendering engine generates final outputs.
5. Choose Approve and Run. An unsaved demonstration offers Save and Run and retains its actions.
6. Pause, resume or cancel while the batch runs. Retry failed items from run history.

Watch Me captures accessible clicks and opted-in field values in explicitly selected running applications. The visible recorder offers pause and sensitive mode. Stop to review and edit the steps. This release does not infer high-level Photoshop/CapCut/FL Studio operations from arbitrary manual gestures.

Home lists unfinished drafts. Restore them after restart. Start Fresh leaves previous drafts available. Run History reports per-item results; clearing history does not remove generated files.

File Quick Tools preview copy/move/rename destinations and find exact duplicates. Undo moves only when the original location is free. Keep backups for external application changes.
