# Troubleshooting
- Missing file: reselect it; moved files are not guessed.
- Output exists: default image mode creates a numbered copy. Choose another destination for application exports.
- Target not found: return to the expected application and window; accessibility names, IDs and titles must match.
- Password field: enter the secret yourself. Do not put it into an ordinary text step.
- Photoshop missing: Quick Tools remains usable; install Photoshop separately for the optional scripting bridge.
- Browser missing: install Microsoft Edge. Do not install Node.js separately; its automation driver is packaged.
- Font missing: image rendering tries the fallback and then an installed font. If none exists it fails clearly.
- Recovery: restore a draft from Home. Completed output may already exist after an interrupted checkpoint; review before repeating external effects.
- Windows verification: Linux compilation cannot validate WPF display, UI Automation, clean installation, DPI behavior or real external applications.
